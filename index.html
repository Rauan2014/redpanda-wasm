Sobre o Panda3DS Web (Emulação ARM11 em WebAssembly)

O Panda3DS Web é uma plataforma educacional e experimental de código aberto que porta o emulador Panda3DS para execução direta no navegador utilizando WebAssembly (WASM), renderização gráfica acelerada por hardware via WebGL2 (OpenGL ES 3.0), síntese de áudio Web Audio DSP e sistema de arquivos persistente local com IndexedDB (IDBFS).

A interface reproduz a experiência de navegação em duas telas (proporções nativas de 400×240 na tela superior e 320×240 na tela tátil inferior) e traz pré-instalado exclusivamente o jogo homebrew open-source Block Blast (distribuído no formato .3dsx sob licença permissiva Zlib) para demonstração imediata.

Requisitos de Sistema e Guia Rápido de Uso

  • Navegadores Compatíveis: Google Chrome 110+, Microsoft Edge 110+, Mozilla Firefox 115+ ou Safari 16.4+ com aceleração gráfica WebGL2 e suporte a WebAssembly multithread.
  • Isolamento de Origem (COOP/COEP): O indicador SAB OK na barra superior do console confirma que SharedArrayBuffer está ativo para desempenho máximo do interpretador ARM11.
  • Formatos Aceitos Localmente: Aplicações homebrew (.3dsx) e backups pessoais descriptografados (.3ds, .cci, .cxi) carregados diretamente do armazenamento do seu dispositivo.
  • Gerenciamento de Saves: O diretório virtual /user salva o progresso automaticamente no IndexedDB a cada retorno ao HOME Menu, permitindo exportar e importar backups completos em .zip.

Perguntas Frequentes (FAQ)

Os arquivos selecionados no meu computador ou celular são enviados para algum servidor?

Não. Toda a leitura de pacotes .3dsx, .3ds, .cci, .cxi e arquivos de salvamento ocorre 100% localmente na memória RAM do seu navegador através da Web File API e do sistema de arquivos virtual do Emscripten (MEMFS / IDBFS). Nenhum binário de jogo é transmitido pela rede.

Por que arquivos criptografados não abrem no emulador?

Em respeito às leis de propriedade intelectual e direitos autorais (DMCA / Lei nº 9.610/1998), o Panda3DS Web não inclui chaves criptográficas proprietárias (AES keys), BIOS ou arquivos de firmware de sistema. O núcleo executa apenas aplicações homebrew de código aberto (.3dsx) ou dumps pessoais previamente descriptografados pelo próprio titular legítimo do cartucho físico.

Como melhorar a performance e a taxa de quadros (FPS) no navegador?

Clique no botão Controle / Teclado na barra utilitária e ajuste a opção Clock ARM11 para 75% (Otimizado) ou 50% (Modo Rápido — Jogos 2D). Isso reduz a quantidade de ciclos de CPU emulados por quadro de vídeo, aumentando a fluidez da renderização WebGL2 em notebooks e dispositivos móveis.

Como conectar controles Bluetooth/USB ou usar o mouse como analógico?

Basta conectar qualquer controle compatível (Xbox, PlayStation DualShock/DualSense, Switch Pro Controller ou 8BitDo) e pressionar um botão para ativar a Web Gamepad API. Se preferir jogar no mouse e teclado, o botão Direcional Mouse permite usar o movimento do cursor para controlar o Circle Pad analógico enquanto clica na tela tátil inferior.
